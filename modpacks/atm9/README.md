# All the Mods 9 – ATM9

Kennung im Update-Manifest: `mstorage-atm9`

## Admin-Launcher

Als Veröffentlichungsordner verwenden:

```text
E:\Git_Modpacks\Minecraft_Launcher\modpacks\atm9
```

Der Admin-Launcher erzeugt darunter:

```text
releases/<version>/mstorage-atm9-<version>.zip
releases/<version>/manifest.json
channel/stable.json
```

Das ZIP wird als Asset eines GitHub Releases mit dem Tag `v<version>` hochgeladen.

## Nutzer-Launcher

Nach dem ersten freigegebenen Release wird diese Manifest-Adresse verwendet:

```text
https://raw.githubusercontent.com/Scholly0988/Minecraft_Launcher/main/modpacks/atm9/channel/stable.json
```

`channel/stable.json` wird erst durch eine ausdrückliche Freigabe im Admin-Launcher erstellt.
