# Minecraft Launcher Updates

Dieses Repository enthält ausschließlich Update-Manifeste für unsere eigenen Änderungen an bestehenden Minecraft-Modpacks.
Die vollständigen Modpacks und fremde Mod-Dateien werden hier nicht weiterverteilt.

## Verwaltete Modpacks

- [All the Mods 9 – ATM9](modpacks/atm9/README.md)

Jedes Modpack besitzt einen eigenen Stable-Kanal. Release-ZIPs werden als GitHub-Release-Assets hochgeladen und nicht direkt in Git gespeichert.
